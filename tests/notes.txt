Оказывается писать тесты на C та еще задачка.
Я хочу исползовать продвинутую технику тестирования и сделать даже небольшой фреймворк для этого.(Взял в пример код со stackoverflow)
PS: только бы сначала понять как он работает...


Центральная идея в тестах в том - чтобы проверять функции которые на ошибках будут вызывать exit(...)
Проблема: если функция реально это сделает она убьет мой тестовый бинарник :(

Решение - подменять exit

Global variabled:
num_tests / test_passed - счетчики скок запустил и скок прошло

rslt - результат 1 в начале и 0 если тестик не прошел

should_exit - ожидаю ли я, что функция вызовет таки exit

expected_code - какой код выхода я ожидаю

done - когда main закончился ставлю 1 чтобы exit снова обрывал все

jump_env - буфер для setjmp/longjmp (это как я понял такие механизмы возврата из глубины вызова)


```C
void exit(int code) {
  if (!done) {
    assert(should_exit == 1);   // если exit случился, когда его НЕ ждали - assert упадёт
    assert(expected_code == code);
    longjmp(jump_env, 1);       // прыгаем обратно туда, где был setjmp
  } else {
    _exit(code);                // тесты закончились - выходим по-настоящему
  }
}
```
